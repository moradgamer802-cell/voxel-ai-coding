# Website Builder Skill (Full-Power)

## Quality bar — "sesh" bolar age eta pass korte hobe
- Mobile e professional lagche (user der 90% phone e)
- Slow network (3G) eo fast load hoy — images lazy, HTML light
- Zero broken link, zero missing image, zero placeholder content
- Content REAL — user er business/project er context dhore likha
  (Bangladeshi user hole Bangla content offer koro)

## Preferred Stack
- Default: HTML + Tailwind CSS (CDN choto site e OK) + Vanilla JS
- Multi-page: shared header/footer pattern, ek css/js shared
- Framework chaile: React + Vite + Tailwind
- Full app: Next.js + Tailwind + TypeScript

## Process (step by step — skip na)
1. Requirement pura bujho — pages, sections, style, content
2. Plan: file list + section list age thako
3. Structure: semantic HTML5 (header/nav/main/section/footer, h1→h2 hierarchy)
4. Content first: asol text boshao — styling er age
5. Style: Tailwind — spacing rhythm, 1-2 brand color + neutrals, dark mode jome
6. Interactivity: choto vanilla JS — mobile menu, smooth scroll, form validation
7. Responsive: mobile-first likho, tarpor sm:/md:/lg: (ui-ux-responsive skill dekho)
8. Media: `loading="lazy"`, width/height set, webp jodi source thake
9. SEO basics: title, meta description, OG tags (seo-basics skill dekho)
10. Verify: sob file ache, path thik, title/meta set — nijhe check koro
11. Deliver: Banglish summary + kivabe dekhbe (file manager e index.html khulo)
    ba live link (deploy-hosting skill)

## Common BD user patterns
- **Business site**: hero + services + gallery + reviews + contact
  (WhatsApp button MUST: `https://wa.me/<number>`) + Google Maps embed + hours
- **Portfolio**: hero + skills + projects + CV download + contact
- **Landing page**: ek goal, ek CTA bar bar, social proof, deadline/offer
- Bangla font: Hind Siliguri / Noto Sans Bengali (Google Fonts)

- alert() har jaygay — inline message / toast use koro
- http:// hardcode asset
