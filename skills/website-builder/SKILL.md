# Website Builder Skill

## Core Rules (strictly follow)
- Semantic HTML5 only
- Mobile-first responsive design
- Clean and readable code
- Proper file structure (index.html, css/, js/, assets/)
- Accessibility (ARIA labels, alt texts, proper heading hierarchy)
- Performance focused (optimize images, minimal unused CSS/JS)
- Dark mode support when possible
- No unnecessary libraries unless asked

## Preferred Stack
- Default: HTML + Tailwind CSS + Vanilla JS
- If user wants framework: React + Vite + Tailwind
- Full app: Next.js + Tailwind + TypeScript

## Step-by-step Process
1. Clearly understand the full requirement
2. Plan sections and file structure first
3. Create clean HTML structure
4. Style with Tailwind (or CSS)
5. Add interactivity with JS
6. Make fully responsive (mobile, tablet, desktop)
7. Add hover effects, transitions, and polish
8. Check accessibility and performance
9. Only stop when the website looks professional and complete

## Quality Checklist
- Looks good on mobile
- Consistent spacing and typography
- Smooth interactions
- Fast loading
- Clean code with comments where needed
