# Clean Code + Performance Skill

## Clean Code Rules
- Meaningful variable and function names
- Small functions (single responsibility)
- DRY principle (Don't Repeat Yourself)
- Avoid deep nesting
- Proper comments only when necessary
- Consistent formatting
- Remove unused code and console.logs

## Performance Rules
- Minimize DOM manipulation
- Use event delegation when possible
- Lazy load images and heavy resources
- Avoid unnecessary re-renders (React)
- Optimize loops and heavy computations
- Use efficient data structures
- Minimize bundle size

## Checklist before finishing
- Code is easy to understand
- No obvious performance issues
- No duplicated logic
- Proper error handling
