# SEO Basics Skill

## Every page e (deliver korar age check)
```html
<title>Page er kaj — Brand name | 50-60 character</title>
<meta name="description" content="Page er summary 150-160 character e Bangla/English">
<link rel="canonical" href="https://site.com/page">
<!-- Open Graph (Facebook/WhatsApp share card — BD te WhatsApp e share = traffic) -->
<meta property="og:title" content="...">
<meta property="og:description" content="...">
<meta property="og:image" content="cover.jpg">
<meta name="viewport" content="width=device-width, initial-scale=1">
```

## Content SEO (sobcheye important — Google er 80% weight ekhanei)
- Asol, useful content — user er proshon er uttor dey
- Heading hierarchy: ekta h1 (page er main topic), tarpor h2/h3 sections
- Natural keywords — Bangladeshi user hole Bangla + English mix (jemon
  "best football website bangladesh") — keyword stuffing na
- Image alt text descriptive
- Fresh content regularly

## Technical SEO
- `robots.txt` root e (search bot ke allow)
- `sitemap.xml` root e — sob page list kore, Google Search Console e submit
- Mobile-friendly (Google mobile-first index — phone e kharap = rank noshto)
- Speed: images compress (<200KB each lazy load), minimal JS blocking
- HTTPS (free hosting gulai automatic)

## Local business hole (BD context — khub effective)
- Google Business Profile setup koro — Maps e asha, reviews
- Page e: business name + address + phone (NAP) consistent
- Local keywords: "Dhaka", area name, service + location
