User model tier select korbe. $ARGUMENTS

Steps:
1. Jodi $ARGUMENTS e tier thake (e.g. "max", "ultra", "mid", "tiny"), seedho `oc-settings model <tier>` chalano (tier na thakle menu unlock koro).
2. Jodi tier na thake, user ke options diye jaanao:
   - Max (default) → voxel/deepseek-v4-flash-free
   - Mid (balanced) → voxel/mimo-v2.5-free
   - Ultra (strong) → voxel/nemotron-3-ultra-free
   - Tiny (smallest) → voxel/ling-3.0-tiny-free
   User choice e `oc-settings model <no>` chalai.
3. Config update hoyeche dekhiye user ke bolo: voxel restart koruk (tahole notun model lagbe).
4. Free model list: `oc-settings models` diye dekhanor option ache — user chaile dekhao.
